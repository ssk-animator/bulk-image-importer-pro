Support — Bulk Image Importer Pro

Bulk Image Importer Pro is an Excel add-in for bulk image importing with row, column, grid, masonry, contact-sheet, and cell-anchored layouts.

Installation help

  • Excel Desktop: run Bulk-Image-Importer-Pro-Setup once, then open Excel and go to Insert > Get Add-ins > Shared Folder.
  • Excel Online / organizations: use the Marketplace installation link (once published) or Microsoft 365 centralized deployment by your admin. Manual manifest upload is for development/testing only.

Troubleshooting

  • Images not importing: use a supported format (PNG, JPG, JPEG, WEBP, BMP, GIF).
  • Add-in not loading: refresh Excel; on Desktop, re-run the installer with Repair.
  • Performance issues: reduce the batch size in Settings.
